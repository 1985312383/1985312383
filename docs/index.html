Torch-RecHub

项目负责人2024.01 至今

负责 Datawhale 推荐算法框架的整体开发与维护，涵盖召回、排序、多任务和生成式推荐。框架提供统一的训练与评测流程，也支持向量检索、模型导出和跨硬件训练。
